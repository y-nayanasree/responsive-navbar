# Responsive Navbar with Hamburger Menu

A responsive navigation bar built using HTML5, CSS3, and JavaScript.

## Features

- Horizontal navigation on desktop screens.
- Hamburger menu on mobile screens.
- Animated menu open and close transitions.
- Navigation links scroll to page sections.
- Active link styling.
- Menu closes after selecting a link.
- Escape key closes the mobile menu.
- Accessible button labels and expanded state.
- Responsive layout with a mobile breakpoint.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

- `index.html` — Website structure
- `style.css` — Navbar styling and media queries
- `script.js` — Menu toggle and navigation interactions

## How to Use

1. Open the website.
2. On desktop, use the horizontal navigation links.
3. On mobile, tap the hamburger icon to open the menu.
4. Tap a navigation link to move to that section.
